### Запуск приложений

- Настольное приложение:
    - Горячая перезагрузка: `./gradlew :desktopApp:hotRun --auto`
    - Обычный запуск: `./gradlew :desktopApp:run`
- Веб приложение:
    - Wasm отслеживание (быстрее, современные браузеры): `./gradlew :webApp:wasmJsBrowserDevelopmentRun`
    - JS отслеживание (медленнее, поддерживает старые браузеры): `./gradlew :webApp:jsBrowserDevelopmentRun`
